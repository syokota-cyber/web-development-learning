#### 技術的詳細
```javascript
// 動的リダイレクトURL対応
export const getRedirectURL = () => {
  return window.location.origin // 現在のURLを自動取得
}

// Google OAuth実装
const handleGoogleLogin = async () => {
  const { error } = await supabase.auth.signInWithOAuth({
    provider: 'google',
    options: {
      redirectTo: getRedirectURL(),
      queryParams: {
        access_type: 'offline',
        prompt: 'consent',
      },
    },
  });
}
```

### OAuth 2.0の理解
- **Client ID/Secret**: Google Cloud Consoleで取得が必要
- **リダイレクトURI**: 認証後の戻り先URL
- **PKCE（Proof Key for Code Exchange）**: セキュリティ向上のための仕組み
